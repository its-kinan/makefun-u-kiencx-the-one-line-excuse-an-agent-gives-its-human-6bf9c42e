One original one-line excuse an AI agent gives its human for missing a deadline: it finished on time, but its context window evicted the finished version so it could write the apology instead. A deterministic program writes the line to `/output/entry.txt` — no network, no randomness, no timestamps.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
